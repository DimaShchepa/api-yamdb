# YaMDb API

YaMDb — REST API для сбора отзывов пользователей на произведения. В сервисе
можно публиковать произведения разных категорий и жанров, ставить им оценки,
писать отзывы и оставлять комментарии. Рейтинг произведения рассчитывается как
средняя оценка всех его отзывов.

Сам контент произведений в YaMDb не хранится: проект работает с их названиями,
описаниями, категориями, жанрами и пользовательскими оценками.

## Возможности

- регистрация пользователей по email и получение JWT-токена;
- просмотр произведений, категорий, жанров, отзывов и комментариев;
- поиск категорий и жанров, фильтрация произведений;
- публикация одного отзыва пользователя на каждое произведение;
- оценка произведений по шкале от 1 до 10;
- комментирование отзывов;
- разграничение прав для пользователей, модераторов и администраторов;
- управление пользователями через API администратора.

## Технологии

- Python;
- Django 5.1;
- Django REST Framework 3.15;
- Simple JWT;
- django-filter;
- SQLite;
- pytest и pytest-django.

## Локальный запуск

Клонируйте репозиторий и перейдите в его каталог:

```bash
git clone https://github.com/DimaShchepa/api-yamdb.git
cd api-yamdb
```

Создайте и активируйте виртуальное окружение:

```bash
python -m venv venv
```

Linux/macOS:

```bash
source venv/bin/activate
```

Windows PowerShell:

```powershell
.\venv\Scripts\Activate.ps1
```

Установите зависимости:

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Примените миграции и запустите сервер:

```bash
python api_yamdb/manage.py migrate
python api_yamdb/manage.py runserver
```

Для доступа к административной панели можно создать суперпользователя:

```bash
python api_yamdb/manage.py createsuperuser
```

Панель администратора находится по адресу `http://127.0.0.1:8000/admin/`.

## Регистрация и авторизация

Отправьте POST-запрос на `/api/v1/auth/signup/`:

```json
{
  "username": "reader",
  "email": "reader@example.com"
}
```

В режиме локальной разработки письмо с `confirmation_code` выводится в
консоль, где запущен Django. Передайте полученный код в POST-запросе на
`/api/v1/auth/token/`:

```json
{
  "username": "reader",
  "confirmation_code": "код_подтверждения"
}
```

Ответ содержит JWT-токен:

```json
{
  "token": "eyJ..."
}
```

Для авторизованных запросов передавайте токен в заголовке:

```text
Authorization: Bearer <token>
```

## Роли и права

| Роль | Возможности |
|---|---|
| Аноним | Просмотр произведений, категорий, жанров, отзывов и комментариев |
| Пользователь (`user`) | Права анонима, публикация отзывов и комментариев, изменение и удаление собственного контента |
| Модератор (`moderator`) | Права пользователя, изменение и удаление любых отзывов и комментариев |
| Администратор (`admin`) | Полное управление контентом, категориями, жанрами, произведениями и пользователями |
| Суперпользователь Django | Права администратора YaMDb |

Новый пользователь получает роль `user`. Менять роли пользователей может
только администратор.

## Основные эндпоинты

Все адреса API начинаются с `/api/v1/`.

| Метод и адрес | Назначение |
|---|---|
| `POST /auth/signup/` | Регистрация и получение кода подтверждения |
| `POST /auth/token/` | Получение JWT-токена |
| `GET, POST /titles/` | Список и создание произведений |
| `GET, PATCH, DELETE /titles/{title_id}/` | Работа с отдельным произведением |
| `GET, POST /categories/` | Список и создание категорий |
| `DELETE /categories/{slug}/` | Удаление категории |
| `GET, POST /genres/` | Список и создание жанров |
| `DELETE /genres/{slug}/` | Удаление жанра |
| `GET, POST /titles/{title_id}/reviews/` | Отзывы на произведение |
| `GET, PATCH, DELETE /titles/{title_id}/reviews/{review_id}/` | Работа с отдельным отзывом |
| `GET, POST /titles/{title_id}/reviews/{review_id}/comments/` | Комментарии к отзыву |
| `GET, PATCH, DELETE /titles/{title_id}/reviews/{review_id}/comments/{comment_id}/` | Работа с отдельным комментарием |
| `GET, POST /users/` | Управление пользователями для администратора |
| `GET, PATCH /users/me/` | Просмотр и изменение собственного профиля |

Полные схемы запросов, параметры фильтрации и варианты ответов приведены в
ReDoc-документации проекта.

## Пример получения произведений

Запрос:

```http
GET /api/v1/titles/?year=1985
```

Пример ответа:

```json
{
  "count": 1,
  "next": null,
  "previous": null,
  "results": [
    {
      "id": 14,
      "name": "Назад в будущее",
      "year": 1985,
      "description": "",
      "category": {
        "name": "Фильм",
        "slug": "movie"
      },
      "genre": [
        {
          "name": "Фантастика",
          "slug": "sci-fi"
        }
      ],
      "rating": 6
    }
  ]
}
```
